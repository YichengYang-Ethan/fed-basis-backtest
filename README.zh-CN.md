# FOMC 决议跨市场相对价值研究

[English project home](README.md) · [研究简报](reports/RESEARCH_BRIEF.pdf) · [复现说明](docs/REPRODUCIBILITY.md) · [数据目录](docs/DATA_CATALOG.md)

项目比较 CME 联邦基金期货日历价差与 Polymarket、Kalshi 决议合约的定价。核心工作包括日历敏感度与状态收益匹配、历史报价对齐、费用及深度验证、10 万美元账户现金与保证金模型。

当前基准是 2026-09-20 的深度成本修正回放：历史账户覆盖 2024-02-01 至 2026-09-01，11 个原始信号、9 笔完成的 **Polymarket + ZQ** 组合，模型期末资产 $126,510.76。累计收益26.5108%，按整个日历区间计算的年化9.5343%；入场条件收益率中位数1.9276%，结算后全阶段资金口径的单笔收益率中位数3.2017%。这些数字不是实盘业绩、无条件预期收益或无风险承诺。

目前的持有至结算策略是研究基准，后续研究重点包括退出时点、合约与执行路径、YES/NO与尾部状态、执行深度和实际账户资本占用。原始设计文档从未在看到结果前冻结，不能称为事先注册实验。

无需 API、无需付费数据的验证：

```sh
make verify
```
